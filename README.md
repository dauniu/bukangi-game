🦈 부캉이 수학 탈출
부산 수로를 헤엄치는 부캉이를 조작해 물고기를 먹고,
사람이 던진 먹이나 쓰레기, 그물을 피하며 최대한 오래 살아남는
어린이용 러너 + 수학 퀴즈 웹게임입니다.

🎮 게임 방법
부캉이는 계속 앞으로 헤엄칩니다.
플레이어는 위아래로 움직이며:
- 🐟 물고기를 먹으면 에너지가 올라갑니다.
- 🍗 생닭에 닿으면 부캉이가 우엑! 하며 에너지가 감소합니다.
- 🥤 버려진 캔에 닿으면 에너지가 감소합니다.
- 🗑️ 쓰레기봉지에 닿으면 에너지가 감소합니다.
- 🥅 그물에 걸리면 게임이 잠시 멈추고 수학 문제가 등장합니다.
- 수학 문제를 맞히면 그물에서 탈출하고 지식 포인트를 얻습니다.
에너지가 0이 되면 게임이 종료됩니다.

⌨️ 조작 방법
PC
- ↑ / W : 위로 이동
- ↓ / S : 아래로 이동
모바일
- 화면 위쪽 터치 : 위로 이동
- 화면 아래쪽 터치 : 아래로 이동

🧮 수학 퀴즈 난이도
게임 시작 전에 난이도를 선택할 수 있습니다.
초급
- 20 미만 덧셈
- 20 미만 뺄셈
중급
- 50 미만 덧셈·뺄셈
- 기본 곱셈
- 기본 나눗셈
고급
- 100 미만 덧셈·뺄셈
- 두 자리 수 × 한 자리 수
- 두 자리 수가 포함된 나눗셈

🏆 오늘의 순위
게임이 끝나면 점수가 Firebase Cloud Firestore에 저장됩니다.
- 모든 플레이어가 같은 순위표를 볼 수 있습니다.
- 총점 기준 TOP 10이 표시됩니다.
- 같은 브라우저에서는 그날의 최고 기록만 갱신됩니다.
- 날짜별로 순위를 저장하기 때문에 매일 새로운 랭킹이 시작됩니다.
- 이전 날짜의 기록은 데이터베이스에 보존됩니다.

🌊 게임 연출
- 수로 배경이 오른쪽에서 왼쪽으로 움직여 부캉이가 앞으로 헤엄치는 느낌을 표현합니다.
- 물결과 물방울 효과가 움직입니다.
- 수로 주변에는 궁구미 응원단이 부캉이를 응원합니다.
- 물고기를 먹으면 만족한 표정의 부캉이로 잠시 변경됩니다.
- 생닭이나 쓰레기에 닿으면 찡그리며 우엑! 하는 표정으로 변경됩니다.

🚀 실행 방법
GitHub Pages
이 프로젝트는 GitHub Pages에서 바로 실행할 수 있습니다.
저장소의:
Settings → Pages
에서
- Source: Deploy from a branch
- Branch: main
- Folder: /(root)
를 선택하면 됩니다.
로컬 실행
간단히 index.html을 브라우저에서 열 수 있습니다.
Firebase 모듈 로딩이나 브라우저 보안 정책 때문에 문제가 생기는 경우에는
로컬 서버 실행을 권장합니다.
python -m http.server 8000
이후 브라우저에서:
http://localhost:8000
으로 접속합니다.

💡 제작 목적
단순한 피하기 게임에 수학 문제를 결합해
아이들이 게임 흐름 속에서 자연스럽게 문제를 풀도록 만드는 것을 목표로 했습니다.
정답을 맞히지 못했다고 바로 게임오버가 되는 방식보다는
힌트를 제공하고 다시 도전할 수 있도록 구성했습니다.

⚠️ 안내
이 프로젝트는 개인 학습 및 교육용으로 제작한 웹게임입니다.
게임 속 동물·먹이·쓰레기·구조 상황은 게임 플레이를 위해 단순화된 표현이 포함되어 있습니다.
야생동물에게 사람이 임의로 먹이를 주거나 가까이 접근하는 행동은 바람직하지 않습니다.

부캉이가 안전히 바다로 돌아갔으면 하는 바람입니다 :)
